# Ultra Abartılı Hesap Makinesi

## Bu Ne?

Bu, insanlığın matematikle olan ilişkisini sonsuza dek değiştirecek tarihi bir projedir. 
Sıradan hesap makineleri sizi yüzüstü bıraktı. Bu makine ise sizi ayağa kaldırır, omuzlarınıza basar ve "İşte sonuç!" diye bağırır.

Gerçekten çalışır. Python ile yazıldı. Terminale şöyle yaz:

```bash
python hesap_makinesi.py
```

Sonra sayıları gir. Dramayı izle. Gül. Ağla. Tekrar dene.

## Neden Var?

Çünkü dünya yeterince abartılı değil. Çünkü 2+2=4 demek sıkıcı. Çünkü evren bize daha fazlasını hak ediyor.

## Uyarılar

- Bu makine sizi matematikten soğutabilir. Veya daha çok sevdirebilir. Belirsiz.
- Sıfıra bölme durumunda evren gerçekten çökmez. Ama öyle hissettirir.
- Çok uzun süre kullanırsanız dramatikleşebilirsiniz. Sorumluluk kabul etmiyoruz.

## Lisans

Herkes kullanabilir. Kimse düzeltmesin. Abartı kalsın.
